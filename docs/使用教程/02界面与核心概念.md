## 辑模式与引擎模式的区别

| 项目        | 编辑模式            | 引擎模式                               |
| ----------- | ------------------- | -------------------------------------- |
| 能否拖卡    | 能                  | 不能直接移动；拖检索卡会进入“注入”流程 |
| 步骤来源    | 手动操作自动记录    | 引擎接受操作后自动记录                 |
| 攻守/指示物 | 可以手动改          | 由引擎计算，不能手动改                 |
| 阶段/回合   | 手动推进            | 由引擎推进，部分按钮禁用               |
| 删除卡      | `Delete` 或右键     | 只能通过右键“移除”并重演               |
| 保存        | 自动保存 + 手动保存 | 保存时同时写入引擎会话快照             |
| 退出        | 无                  | “退出引擎”会挂起会话，可继续           |

## 卡片检索

搜索框、搜索按钮、筛选按钮

![image-20261026085941453](../images/image-20261026085941453.png)

一个关键词可以命中卡片上的四类内容，命中任意一类即算找到：

- 卡名
- 效果文本
- 字段
- 卡密

### 搜索语法

![image-20261026085951136](../images/image-20261026085951136.png)



| 写法          | 作用               | 匹配范围                                                     |
| ------------- | ------------------ | ------------------------------------------------------------ |
| `关键词`      | 普通搜索           | 卡名 / 效果文本 / 字段，任一包含即可搜索到                   |
| `词1 词2`     | 空格分隔多个关键词 | 每个关键词都要命中才能搜索                                   |
| `"青眼 白龙"` | 引号短语           | 引号内作为一个整体关键词，可包含空格                         |
| `-关键词`     | 排除               | 命中该关键词的卡全部剔除                                     |
| `$关键词`     | 仅卡名             | 只搜卡名，不看效果文本和字段                                 |
| `@关键词`     | 仅字段             | 只按字段匹配                                                 |
| `89631139`    | 纯数字             | 按卡密搜（含异画卡指向的原始密码），并附带匹配卡名里含这串数字的卡 |

前缀可以组合：`-$青眼`（卡名含青眼的排除）、`-@青眼`（排除青眼字段）、`$"青眼 白龙"`（卡名整体包含「青眼 白龙」）都合法

例子：

| 搜索词               | 含义                           | 典型结果                                                     |
| -------------------- | ------------------------------ | ------------------------------------------------------------ |
| `青眼`               | 卡名/文本/字段含「青眼」       | 青眼白龙、青眼亚白龙，以及效果里提到「青眼」的卡（如传说之白石） |
| `青眼 白龙`          | 同时含「青眼」和「白龙」       | 青眼白龙、青眼亚白龙等，但不含效果里只有「青眼」没有「白龙」的卡 |
| `$青眼`              | 仅卡名含「青眼」               | 青眼的本体卡，不再命中效果里提到「青眼」的白石之类           |
| `@青眼`              | 字段为「青眼」                 | 青眼字段全部卡                                               |
| `@幻影 -@幻影骑士团` | 幻影系列但排除幻影骑士团       | 需要区分近亲字段时特别有用                                   |
| `龙 -炎`             | 含「龙」但排除含「炎」的       | /                                                            |
| `融合 -@青眼`        | 文本含「融合」且不属于青眼系列 | /                                                            |
| `89631139`           | 按密码搜                       | 直接定位青眼白龙                                             |

### 筛选语法

攻击、守备、星数、刻度都支持 `>`、`>=`、`<`、`<=`、`=` 前缀，不写前缀等同于 `=`

### 收藏

可以收藏卡片，**默认是未分类**

一张卡片仅会收藏在未分类或者分类里面，但**可以有多个分类**

删除分类，**会删除整个分类下的收藏，但不会影响其他分类**
