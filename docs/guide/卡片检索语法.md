# 卡片检索语法

## 可以搜什么

一个关键词可以命中卡片上的四类内容，命中任意一类即算找到：

| 可搜内容 | 说明 |
| --- | --- |
| 卡名 | 含异画卡指向的原名 |
| 效果文本 | 卡片的描述文字 |
| 系列 | 字段 / 卡片名集团（`strings.conf` 里的字段名） |
| 卡片密码 | 输入纯数字即按密码搜 |

## 语法总览

| 写法 | 作用 | 匹配范围 |
| --- | --- | --- |
| `关键词` | 普通搜索 | 卡名 / 效果文本 / 系列，任一包含即命中 |
| `词1 词2` | 空格分隔多个关键词 | 每个关键词都要命中（AND） |
| `"青眼 白龙"` | 引号短语 | 引号内作为一个整体关键词，可包含空格 |
| `-关键词` | 排除 | 命中该关键词的卡全部剔除 |
| `$关键词` | 仅卡名 | 只搜卡名，不看效果文本和系列 |
| `@关键词` | 仅系列 | 只按字段（系列/卡片名集团）匹配 |
| `89631139` | 纯数字 | 按卡片密码搜（含异画卡指向的原始密码），并附带匹配卡名里含这串数字的卡 |

前缀可以组合：`-$青眼`（卡名含青眼的排除）、`-@青眼`（排除青眼系列）、`$"青眼 白龙"`（卡名整体包含「青眼 白龙」）都合法。

## 匹配规则说明

- **全部是「包含」匹配，不是全等**。搜 `龙` 会命中青眼白龙、真红眼黑龙、龙星……只要名字/文本/系列里出现这两个字就算。
- **不带前缀时范围最宽**：卡名、卡片描述（效果文本）、所属系列三者任一包含即命中。
- **`$` 收窄到卡名**：适合「我明确知道名字里有这个词，但效果文本里到处都是它」的场景。
- **`@` 只看系列**：按 `strings.conf` 里的字段名匹配。系列词**少于 2 个字时要求完全相等**（避免单字误伤一大片），2 个字以上是包含匹配。
- **多个关键词是 AND 关系**：`龙 炎` 要求两个词都命中，结果是「含龙且含炎」的卡。
- **`-` 排除的是整个命中结果**：`龙 -炎` 会把「卡名/文本/系列里出现炎」的龙卡全部去掉，包括效果文本里提到「炎属性」的。

## 例子

| 搜索词 | 含义 | 典型结果 |
| --- | --- | --- |
| `青眼` | 卡名/文本/系列含「青眼」 | 青眼白龙、青眼亚白龙，以及效果里提到「青眼」的卡（如传说之白石） |
| `青眼 白龙` | 同时含「青眼」和「白龙」 | 青眼白龙、青眼亚白龙等，但不含效果里只有「青眼」没有「白龙」的卡 |
| `$青眼` | 仅卡名含「青眼」 | 青眼家族的本体卡，不再命中效果里提到「青眼」的白石之类 |
| `$"青眼 白龙"` | 卡名整体包含「青眼 白龙」 | 青眼白龙；不会命中「青眼 亚白龙」（中间字不同） |
| `@青眼` | 系列为「青眼」 | 青眼系列全部卡，包括名字里没有青眼的（如「龙骑士 青眼」同类支援卡） |
| `@幻影 -@幻影骑士团` | 幻影系列但排除幻影骑士团 | 需要区分近亲系列时特别有用 |
| `龙 -炎` | 含「龙」但排除含「炎」的 | 火山龙、炎龙这类会被一并排除 |
| `融合 -@青眼` | 文本含「融合」且不属于青眼系列 | 找泛用融合素材/支援时用 |
| `89631139` | 按密码搜 | 直接定位青眼白龙 |

## 图形筛选规则

攻击 / 守备 / 星数 / 刻度都支持 `>`、`>=`、`<`、`<=`、`=` 前缀，不写前缀等同于 `=`
