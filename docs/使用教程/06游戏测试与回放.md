# 06游戏测试与回放

## 四条路径的区别

![image-20261026133542071](../images/image-20261026133542071.png)

| 功能             | 导出内容        | 需要引擎                | 支持人数      | 进游戏方式                  |
| ---------------- | --------------- | ----------------------- | ------------- | --------------------------- |
| 使用游戏测试该局 | 当前台面的 Lua  | 不需要                  | 1v1           | 自动启动（EDOPro 需手动选） |
| 导出脚本         | 当前台面的 Lua  | 不需要                  | 1v1、2v2 标准 | 手动加载                    |
| 导出对局回放     | YRP/YRP3D + Lua | 需要，且至少有 1 个操作 | 1v1、2v2 标准 | 自动启动（EDOPro 需手动）   |
| 导入对局回放     | 读取 YRP/YRP3D  | 会用引擎重放            | 1v1、2v2 标准 | 在编辑器里看                |

## 导出对局回放

![image-20261026140335390](../images/image-20261026140335390.png)

### 选择回放格式（支持上帝视角、我方视角、观战视角）

点「导出对局回放」后先选

![image-20261031215833962](../images/image-20261031215833962.png)

![image-20261031220748552](../images/image-20261031220748552.png)

| 选项                     | 文件                  | 观看方式                  | 手牌                       |
| ------------------------ | --------------------- | ------------------------- | -------------------------- |
| YRP（ygopro / EDOPro）   | `replay/<名称>.yrp`   | ygopro、EDOPro 的录像回放 | 双方手牌可见               |
| YRP3D · 回放（我方视角） | `replay/<名称>.yrp3d` | 只能在 MDPro3 观看        | 我方手牌可见，对方显示卡背 |
| YRP3D · 观战             | `replay/<名称>.yrp3d` | 只能在 MDPro3 观看        | 双方手牌都显示为卡背       |

YRP3D 需要 MDPro3 主目录，如果没有设置，导出时会提醒

也可以手动提前设置

![image-20261031220414927](../images/image-20261031220414927.png)

### 前置条件

- 当前有引擎会话
- 引擎时间线至少有 1 个操作（不只是初始节点）
- 对阵是 1v1 或 2v2 标准
- 引擎会话里没有注入操作（手动加卡、置顶/置底、调整 LP 等）；有的话导出前会先自动重打
- 选 YRP3D 时，游戏目录或 MDPro3 目录里要有 MDPro3

### 导出/打开回放时自动重打

会话里有注入、替换等操作时，点「导出对局回放」或用游戏打开当前回放，**程序会先自动重打**

### 它会做什么

1. 把引擎会话的响应流、种子、初始台面打包成回放
2. 1v1 会写一份对应的 Lua 到 `single/`（单人模式）
3. 写 `replay/<名称>.yrp` 或 `replay/<名称>.yrp3d`（按所选格式）

### 回放文件依赖

单模式回放依赖同名的 `single/<名称>.lua`。如果只拷贝 `.yrp` / `.yrp3d` 到另一台机器，没有对应 Lua，回放可能无法加载或无法还原初始场面。换机器时把 `replay` 和 `single` 一起带走

**1v1 单模式回放必须同时有回放文件和 Lua 两个文件**（2v2 tag 回放除外，因为卡组信息写在回放里，不需要单模式 Lua）

## 用游戏打开当前回放

菜单：游戏 → 用游戏打开当前回放

- 正在看导入的回放：把回放文件复制到游戏的 `replay` 目录并启动客户端；`.yrp3d` 只能用 MDPro3 打开，游戏目录是 ygopro 时会提示切换
- 当前有引擎会话（或挂起的会话）：先按当前游戏类型导出再启动。游戏目录是 MDPro3 时用 YRP3D 我方视角，否则用 YRP
- 会话里有注入操作：和导出一样，先自动重打
- 没有会话也没有导入回放：会提示先导入回放或打一局

导出、打开和自动重打期间会有全屏加载提示，等提示消失再操作。

## 回放文件管理

- 只列出 `replay` 目录里同时存在同名 `single/*.lua` 的回放（`.yrp` 和 `.yrp3d`）
- 勾选后删除，会同时删除回放和对应 Lua
- 用于清理导出的测试回放，避免越积越多

### 回放控制

- **播放/暂停**：底部播放键，或空格
- **上一步/下一步**：左右箭头，或 `←` / `→`
- **速度**：0.5×、1×、1.5×、2×、3×
- **回到开头**：旋转箭头
- **退出回放**：回到导入前的工程
- **编辑**：从当前回放步骤转成可编辑工程

![image-20261026144717144](../images/image-20261026144717144.png)

### 编辑回放

点“编辑”：

1. 以当前回放步骤为分叉点
2. 把该步之前的步骤保留
3. 把当前台面转成编辑器格式
4. 退出回放，进入可编辑状态
5. 标题会变成“A vs B”形式

之后的步骤不会保留
