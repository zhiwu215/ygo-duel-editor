# 游戏王决斗编辑器：额外卡组表侧放置与角标显示

本改动属于一次独立的原子化功能提交，旨在支持游戏王规则中额外卡组表侧表示（如灵摆怪兽置入额外卡组）的摆牌与视觉呈现需求。通过扩展 `Ctrl` 拖拽修饰键、落子浮条快速切换、右键菜单项及卡面高亮角标，完善了额外卡组的双态（表侧/里侧）做场能力。

---

## 改动缘由与核心设计目标

- **支持灵摆怪兽等额外表侧规则**：在游戏王实机规则中，灵摆怪兽从场上送去墓地或受特定效果影响时，须表侧表示加入额外卡组。此前编辑器额外卡组只能里侧盖放，无法满足灵摆卡组及现代残局的编排需求。
- **扩展 `Ctrl` 拖拽放置修饰键**：按住 `Ctrl` 拖拽卡片落入额外卡组时，自动覆盖默认的里侧盖放状态，直接以表侧表示 (`FACEUP`) 放入。
- **表侧高亮角标与真图呈现**：当额外卡组最顶层卡片为表侧表示时，在卡片左上角浮出醒目的青蓝色「表侧」角标，并直接渲染卡面真实大图替代经典卡背。
- **全链路表示形式切换支持**：在槽位落子浮条 `DropHintPopover` 与全局卡片右键菜单中，为额外卡组与主卡组卡片补充「表侧表示 / 里侧表示」切换功能。

---

## 前端设计思考与样式体系

### zoneDrop 工具类理解

#### 命名含义与工具职责

- **`zone`（区域/格子）**：游戏王决斗盘里的各个格子（怪兽区、魔陷区、手牌区、额外卡组、主卡组等）；
- **`drop`（落子/松开鼠标放下）**：从检索区或场上用鼠标把卡牌拖动过来、松手“落入”格子的操作；
- **职责定位**：专门负责计算“卡片拖拽落入某个区域时，应该以何种表示形式（表侧/里侧、攻击/守备、公开/私密）放置”的落子规则助手。

#### 核心解决的操作痛点

- 在传统编辑器中，每次拖入卡片往往都要弹出一个确认弹窗询问表示形式，在连续摆放几十步做场或排布残局时非常打断心流；
- 编辑器为此制定了各区域的常规“默认放置状态”：怪兽默认表攻、魔陷默认盖放、手牌默认不公开、额外卡组默认里侧盖放；
- 当作者需要直接发动魔法、让怪兽直接盖守、或将灵摆怪兽表侧置入额外卡组时，无需落子后再右键修改，直接按住键盘 `Ctrl` 键拖放即可一步到位切换状态。

#### 参数与状态切换逻辑拆解

函数 `getDropPosOverride(location, invert)` 接收两个参数并计算覆盖后的表示形式：

- **`location`（目标区域）**：卡片正要落入的目标区域（`CardLocation` 常量）；
- **`invert`（是否反转切换）**：是否按住了键盘上的 `Ctrl` 键（即事件对象的 `e.ctrlKey`）。

内部判断逻辑：

- **未按住 `Ctrl` (`!invert`)**：直接返回 `undefined`，表示无需特殊干预，直接沿用该区域的常规默认放置形式；
- **按住 `Ctrl` 拖入魔陷区 (`SZONE`)**：由默认盖放切换为 `CardPosition.FACEUP`（表侧直接发动）；
- **按住 `Ctrl` 拖入怪兽区 (`MZONE`)**：由默认表攻切换为 `CardPosition.FACEDOWN_DEFENSE`（里侧守备盖放）；
- **按住 `Ctrl` 拖入手牌区 (`HAND`)**：由默认私密切换为 `CardPosition.FACEUP`（手牌公开，常用于残局教学展示关键起手件）；
- **按住 `Ctrl` 拖入额外卡组 (`EXTRA`)**：由默认里侧切换为 `CardPosition.FACEUP`（表侧表示，用于灵摆怪兽置入额外卡组）；
- **按住 `Ctrl` 拖入主卡组 (`DECK`)**：由默认里侧切换为 `CardPosition.FACEUP`（表侧置入，支持特定表侧效果）。

#### 交互口诀与映射总结

- **普通拖放**：沿用区域常规默认状态；
- **按住 `Ctrl` 拖放**：一键反转切换为特定表示形式（直接发动 / 盖守 / 手牌公开 / 额外表侧）。

### 额外表侧角标视觉语言 (`CardItem.tsx`)

- **青蓝高亮角标**：
  `absolute top-1 left-1 bg-cyan-600/90 text-white font-sans text-[8px] font-bold px-1 py-0.5 rounded border border-cyan-400/50 shadow backdrop-blur-xs`
  - `bg-cyan-600/90 text-white`：采用明亮的青蓝色调与纯白文字，与常规场上盖放的暗金琥珀色（`bg-black/85 text-amber-300`）形成清晰色相区分，第一时间传达「灵摆/表侧」概念；
  - `border border-cyan-400/50` 与 `shadow`：精细的半透明边框与投影，确保在任何复杂卡图背景下均具备优良可读性；
  - `backdrop-blur-xs`：微量高斯模糊提升质感。

### 快捷键帮助联动 (`MenuBar.tsx`)

- 在顶部菜单栏「帮助 -> 快捷键参考」弹窗中，更新 `Ctrl + 拖放` 的修饰键说明，明确标注「魔陷直接发动 / 怪兽盖守 / 手牌公开 / 额外表侧」，降低用户探索心智成本。

- **改动缘由**：在 `getDropPosOverride` 中补充对 `CardLocation.EXTRA` 与 `CardLocation.DECK` 的支持。当按住 `Ctrl` 拖入额外卡组或主卡组时强制覆盖为表侧表示 (`CardPosition.FACEUP`)。

```diff
 export function getDropPosOverride(location: number, invert: boolean): number | undefined {
   if (!invert) return undefined
   if (location === CardLocation.SZONE) return CardPosition.FACEUP
   if (location === CardLocation.MZONE) return CardPosition.FACEDOWN_DEFENSE
   if (location === CardLocation.HAND) return CardPosition.FACEUP
+  if (location === CardLocation.EXTRA) return CardPosition.FACEUP
+  if (location === CardLocation.DECK) return CardPosition.FACEUP
   return undefined
 }
```
