# 游戏王决斗编辑器：桌面原生双层顶栏与决斗工作台重构

本改动属于一次独立的原子化提交，旨在重塑编辑器的顶部控制架构。针对此前单行 56px 顶栏元素拥挤、层级混杂的问题，重构为符合现代桌面创作软件标准的**双层顶栏体系**（第一行桌面系统菜单栏 + 第二行决斗工作台专用工具栏），并扩充对阵互换控制。

---

## 改动缘由与核心设计目标

- **系统级操作与决斗编排操作解耦**：将通用的“工程保存/打开、Lua 导入导出、主题切换、快捷键指引”归入桌面原生下拉菜单栏；将对局编排最高频的“大师规则切换、双方 LP 输入、先攻执骰、撤销重做、对阵翻转与导出”收拢在工作台工具栏，形成层级分明的视觉主次。
- **引入标准桌面下拉菜单栏 (MenuBar)**：实现包含「文件」、「编辑」、「设置」、「帮助」四大菜单的原生交互，支持鼠标滑过跨菜单自动展开、快捷键说明与绑定、Esc / 点击外部平滑关闭。
- **提供一键对阵翻转 (swapSides)**：编排对局时经常需要对调双方场面视角，提供挂入撤销历史的双方控制权反转原子能力。
- **全局快捷键网络**：统一在顶栏监听挂载 `Ctrl+N`（新建）、`Ctrl+O`（打开工程）、`Ctrl+S`（保存工程）、`Ctrl+I`（导入 Lua）、`Ctrl+E`（导出 Lua）、`Ctrl+Z`（撤销）与 `Ctrl+Y`（重做），键盘操作与菜单无缝协同。
