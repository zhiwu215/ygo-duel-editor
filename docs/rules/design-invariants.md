# 交互行为规则与核心操作不变量 (Design Invariants)

> 本文档是 YGO Duel Editor 的**用户行为与操作契约**。AI 编码代理在新增功能、重构或修复 Bug 时，**无论采用何种技术实现与架构设计，都必须确保本文档中列出的所有用户操作完整可用、不可退化**。

---

## 核心原则

1. **编排优先**：本软件核心是决斗编排与残局制作工具。无论引擎判定当前处于何种阶段（如抽卡阶段、对方回合等），用户始终保有自由移动、摆放、召唤、送墓卡片的基础操作能力，严禁吞没操作菜单。
2. **黑盒行为契约**：不限制具体的代码实现方式（无论是事件派发、状态机还是组件架构），只严格约束用户操作的输入、响应与预期结果。

---

## 核心操作清单

### 1. 主卡组区
- **空卡组右键**：必须弹出「切换卡组」对话框，允许导入/更换卡组。
- **已有卡片的主卡组右键**：必须弹出右键菜单（包含「切换卡组」等操作）。
- **主卡组左键单击**：执行抽卡 1 张到手牌。

### 2. 手牌区
- **手牌左键单击**：弹出 YGOPro 风格实战动作按钮（如通常召唤、特殊召唤、盖放、发动等）。
- **手牌右键单击**：弹出完整操作菜单（通常召唤到指定位置、特殊召唤、覆盖、送去墓地、除外等）。

### 3. 场地区域（前场怪兽区 / 后场魔陷区 / 场地魔法格）
- **场上卡片左键单击**：弹出实战动作按钮（变更表示形式、发动效果、声明攻击等）。
- **场上卡片右键单击**：弹出自由编辑菜单（送去墓地、除外、返回手牌、返回卡组、翻面等）。
- **墓地 / 除外区 / 额外卡组**：
  - 点击或双击对应格子/牌堆时，展开卡片列表查看窗口，允许浏览与取用卡片。

### 4. 动作悬决流程（选择召唤位置 / 选择攻击目标 / 选择效果对象）
- **发起动作后**：场上必须出现目标指示（如合法格子高亮提示）。
- **左键点击目标**：确认并执行该操作。
- **右键任意空白处或按 Esc 键**：
  - **必须干净取消当前动作**，退出悬决状态，手牌/场面保持不变。
  - **严禁在取消时误触发下层的右键菜单或格子编辑弹窗**。
