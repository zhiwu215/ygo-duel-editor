## 选择对阵人数

- **1 v 1**：最常用，内置引擎和游戏测试都支持
- **2 v 2 标准**：每队 2 人，共用队伍 LP，固定先后攻顺序（我方 1 → 对方 2 → 我方 2 → 对方 1）。这是 Tag Duel 规则。标准 2v2 启动引擎时，同队两人的手牌数必须相同，否则会拒绝启动
- **2 v 2 独立 LP**：每队 2 人，各自 LP，先后攻顺序按徽章设置。只用于剧情编排和近似校验，不能按 tag 规则导出
- **自定义人数**：1-6 对 1-6，用于多人剧情。不能导出 Lua/回放，引擎只能近似校验

## 往盘面放卡

### 从检索区拖入

随便放

![image-20261028132351368](../images/image-20261028132351368.png)

### 放置规则

- 魔陷区、场地魔法区、灵摆区是“独占格”。**目标格已有卡时，新卡会替换掉原来的卡**
- 手牌、主卡组、额外卡组、墓地、除外区是“堆”。从检索区拖到卡堆格，**会插到该卡堆的最上面**
- 想把卡插到卡堆中间，先双击打开卡堆列表，再在列表里拖到目标位置
- 拖到手牌空白处会加到当前视角决斗者的手牌末尾；拖到某张手牌上会插到该位置附近
- **从检索区放卡不会生成步骤**。它只是改变盘面

### 默认表示形式与 `Ctrl`

在快捷键中中有说明

![image-20261026104549109](../images/image-20261026104549109.png)

不同区域的默认表示形式不同：

| 目标区域 | 默认     | 按住 `Ctrl` 拖放 |
| -------- | -------- | ---------------- |
| 怪兽区   | 表侧攻击 | 里侧守备         |
| 魔陷区   | 里侧盖放 | 表侧发动         |
| 额外卡组 | 里侧     | 表侧             |
| 主卡组   | 里侧     | 表侧             |
| 墓地     | 表侧     | 表侧             |
| 除外区   | 表侧     | 表侧             |

### 从卡堆拿卡

打开卡堆列表（双击卡堆），把卡拖到目标区域；也可以点卡堆列表里的“持卡”按钮，让卡跟随鼠标，再点击目标格

## 卡堆管理

### 打开列表

- 双击主卡组、额外卡组、墓地、除外区
- 或者右键卡堆格 → “查看列表 (N)”
- 卡堆列表里可以用右上角搜索框按卡名/卡密过滤；过滤时不能拖拽排序

![image-20261026105125234](../images/image-20261026105125234.png)

列表里：

- 左上角 `#1`、`#2` 是顺序，`#1` 是卡组顶/墓地顶
- 拖拽卡片可以调整顺序
- 悬停底部会出现“持卡”和“删除”按钮
- 额外卡组的卡右上角可以切“表侧/里侧”
- 主卡组 `#1` 会标“下一抽”

### 抽卡

编辑模式下，单击主卡组格会抽一张到手牌

- 单击和双击有 240ms 的延迟区分：双击会取消抽卡并打开列表
- 抽卡会生成一个“抽卡”步骤
- 引擎模式下不能用，抽卡由引擎的抽卡阶段处理

![image-20261026105229671](../images/image-20261026105229671.png)

### 清空卡堆

右键卡堆里的卡 → “清空主卡组/墓地/...”

清空会移除该卡堆所有卡

![image-20261026105249510](../images/image-20261026105249510.png)

## 手牌管理

### 放入手牌

- 从检索区拖到手牌区
- 从卡组列表拖到手牌
- 主卡组抽卡
- 从场上/墓地/除外拖回手牌

### 手牌顺序

在手牌区内左右拖拽可以调整顺序

拖到某张卡的左半边/右半边，会在它前面/后面插入

### 手牌占位卡

- “添加占位卡”：添加一张未定卡，用于“不知道对方手牌是什么”的剧情
- “从手牌移除”：直接删除

占位卡使用卡密 99999999

![image-20261026112928297](../images/image-20261026112928297.png)

引擎模式下，可以在手牌上右键把它“作为怪兽/作为魔陷”，或者用命令菜单转换。导出到游戏时，占位卡会按所在区域映射成怪兽/魔陷占位卡

![image-20261026112953961](../images/image-20261026112953961.png)

## 超量素材

### 放素材

怪兽区域，把卡片A拖放到卡片B上，B就会成为素材

右下角出现琥珀色数字徽章，表示素材数量

![image-20261026113334609](../images/image-20261026113334609.png)

### 查看和管理

双击超量怪兽，或点右下角数字徽章，打开“超量素材”列表

列表里可以拖拽排序、持卡、删除

![image-20261026113658655](../images/image-20261026113658655.png)

右键超量怪兽 → “拔除素材”，勾选要拔除的素材，确认后送去墓地

![image-20261026113454355](../images/image-20261026113454355.png)

### 引擎限制

内置引擎建卡时不接受 `LOCATION_OVERLAY`，所以启动引擎后超量素材无法还原

## 衍生物

衍生物通过“卡片效果文本里的衍生物建议”来放：

1. 按住 `Shift` 点一张场上的卡，打开攻守/指示物面板（引擎模式不适用）
2. 面板底部是“衍生物”区。它会根据这张卡的效果文本，从卡库里匹配可能的衍生物
3. 点一个衍生物，进入“待放置”状态
4. 点一个空怪兽区放下
5. 按 `Esc` 或点“取消放置”退出待放置

![image-20261026120342694](../images/image-20261026120342694.png)

## 指示物与自定义攻守

### 打开面板

按住 `Shift` 点场上的一张怪兽/魔陷/场地/灵摆卡。

面板包括：

- 攻击力、守备力计算器
- 当前指示物列表，可添加指示物下拉框，或者自定义指示物输入；
- 衍生物建议

修改后，可以使用战术透视查看

![image-20261026121208865](../images/image-20261026121208865.png)

### 引擎模式

引擎模式下 `Shift+左键` 不会打开编辑面板；攻守、指示物由引擎维护

> 自定义 ATK/DEF 只在编辑器里显示和保存，不会写进导出的 Lua，也不会带入引擎；客户端按卡库原始数值显示。需要真实攻守变化时，用效果在引擎/客户端里结算

## 删除与清空

- 鼠标悬停或选中卡，按 `Delete` / `Del`
- 右键卡 → “从场上移除 / 从手牌移除 / 清空卡堆”
- 卡堆列表里悬停卡 → 垃圾桶

引擎模式下不能直接删除；右键“移除”会修改来源并重演

## 开始对局与阶段

盘面中间的按钮：

- 未开始时是“开始”。
- 点“开始”有两个选项：
  - **抽 5 张**：按先后攻顺序，每名决斗者从主卡组抽 5 张，生成抽卡步骤，然后进入对局。
  - **不抽牌**：不抽卡，直接进入对局。
- 开始后，中间按钮变成阶段按钮，两侧出现阶段状态和结束阶段按钮。

![image-20261026121414539](../images/image-20261026121414539.png)

编辑模式下，每次推进都会生成阶段更替/回合更替步骤；引擎模式下会向引擎提交对应命令，能不能推进由引擎决定
