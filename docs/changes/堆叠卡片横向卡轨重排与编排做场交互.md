# 游戏王决斗编辑器：堆叠卡片横向卡轨重排与编排做场交互

本改动属于一次独立的原子化功能提交，旨在实现堆叠卡组列表内的深度编排与交互能力。废除单步左右移动箭头的繁琐操作，重构为现代化的横向卡轨流；支持卡框鼠标直接拖拽推挤换位并辅以单侧定向强光指示光柱；支持直接拖动卡图出弹窗到场上或手牌做场；右键菜单提供全套做场转移动作；全面支持从外部检索区直接拖拽卡片定向插入或末尾追加，底层 sequence 自动连续平移并纳入撤销/重做。

---

## 改动缘由与核心设计目标

- **直接拖拽推挤重排替代低效箭头**：传统左右箭头每次只能将卡片位移一格，面对数十张卡片时极其繁重。重构为用户按住白色外框即可在横向卡轨内左右推动卡片实时换位，松手即刻触发排序更新。
- **单侧强光光柱（Directional Drop Beam）精准指示落点**：
  - 传统整卡高亮无法明确告知编排者卡片即将插在目标卡片的前面还是后面；
  - 新增精确坐标检测与单侧定向强光系统：鼠标悬停在卡片左半部时，左侧立即激发深天蓝色垂直脉冲光柱与向右微光渐变，指示「插在此卡前」；悬停在右半部时，右侧激活动态光柱与向左微光渐变，指示「插在此卡后」；
  - 放置算法依据拖拽来源与目标序号精准计算偏移量，杜绝落点差位。
- **支持从右侧检索面板直接拖拽卡片插入列表**：
  - 做场编排者在检视额外卡组或墓地列表时，常需要从右侧卡片库直接补充卡牌入堆；
  - 列表弹窗横向卡带及每张卡牌外框均全面支持接收外部原生拖拽（`application/json` 与 `text/instanceId`）：拖到具体某张卡片前后可激活单侧强光精准插入，拖至末尾或空区域可自动追加至堆底；
  - `useDuelStore` 的 `addCardToZone` 与 `moveCard` 针对堆叠区域执行 sequence 平移操作，将插入点之后的所有卡片 sequence 自动递增 1，严格保持从 0 到 N-1 的连续索引。
- **双层拖拽隔离（拖卡图做场 vs 拖卡框重排）**：
  - **拖动卡框（Outer Tile）**：按住白色外框在列表内左右推动实现内部顺序调整，弹窗始终保持打开；
  - **拖动卡图（Inner Cover）**：直接拖拽卡图即可移出弹窗放置到场上或手牌，拖拽启动后 60ms 弹窗自动隐去让出决斗盘视野。
- **操作动作统一收拢至右键上下文菜单**：
  - 避免在宽度仅 144px 的卡片底栏上平铺过多微型按钮；
  - 将回到手牌、送去墓地、除外、回到主卡组、回到额外卡组、从决斗移除等多元化操作统一交由右键上下文菜单（及卡片底栏「···」按钮）承载，支持智能识别怪兽类别（额外怪兽、主卡组怪兽、灵摆怪兽）。

### 堆叠卡片筛选与排序逻辑理解

#### 堆叠区域与场表格子的本质差异

- **场上怪兽区 / 魔陷区**：拥有 5 个物理格子，每个格子拥有固定的槽位序号（`sequence` 为 `0, 1, 2, 3, 4`），每个格子里同一时刻通常只能容纳一张卡；
- **堆叠区域（额外卡组、主卡组、墓地、除外区）**：在决斗盘上网格物理上仅占据一个槽位，但这一个区域内会放置多张甚至数十张卡片；
- **共享相同的控制者与区域**：在该堆叠区域内部的所有卡片，其 `controller`（谁的卡）和 `location`（哪个区域）是完全一致且共享的。

#### filter 提取整叠卡片的依据

正因为同一卡堆中的所有卡片具有完全相同的控制者与区域标识，因此只要执行条件过滤：

```typescript
.filter((c) => c.controller === controller && c.location === location)
```

就能从全局扁平存储所有场面卡片的 `cards` 大数组中，精准、一张不漏地筛选出属于该目标卡堆的全部卡片集合。

#### sort 还原物理堆叠层级的必要性

在整叠卡片被筛选出来之后，界面需要知道谁压在谁上面、谁是堆顶第一张、谁在堆底最后一张：

- **物理堆叠次序（`sequence`）**：在数据模型中，堆叠区域卡片的 `sequence` 严格代表从顶到底的层次序号（`sequence: 0` 为最顶层卡片，也是场面默认露出的卡面；数值越大越靠近堆底）；
- **执行排序**：由于在编辑与拖拽过程中，全局数组内元素的追加或挪动并不保证绝对有序，因此必须调用：

```typescript
.sort((a, b) => a.sequence - b.sequence)
```

将卡片按照 `sequence` 升序排列，从而 100% 还原其在真实物理世界中「从第一张到最后一张」的线性堆叠次序，列表弹窗方能准确无误地从左到右平铺展开。

#### 数组换位与 sequence 连续索引重构

在列表内通过鼠标左右推动卡片换位时，执行标准的前端换位与重编号流程：

- **抽离与插入**：从原位置 `fromIndex` 抽离目标卡片，并插至新位置 `toIndex`；
- **重新编号**：遍历换位后的新数组，重新为每张卡赋值从 `0` 到 `N-1` 连续递增的 `sequence`；
- **不可变更新与撤销追踪**：通过 Zustand 不可变更新将新的次序写回全局状态，使所有做场重排操作均可被 `Ctrl+Z` 历史完整撤销与重做。

### **src/renderer/src/stores/useDuelStore.ts**

- **改动缘由**：

  - 在 `addCardToZone` 与 `moveCard` 针对堆叠区域插入卡片时，将后续卡片 sequence 自动平移递增 (+1)，保持严格递增索引。
