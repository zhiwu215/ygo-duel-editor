# 游戏王决斗编辑器：拖拽修饰键与落子表示浮条交互重构

本改动属于一次独立的原子化提交，旨在提升做场摆牌的连续操作效率。废除在放置卡片时弹出模态弹窗询问表示形式（攻击/守备/盖放/发动）的阻塞式旧方案，重构为 **`Ctrl` 键拖拽切换默认放置状态** 与 **落子后非阻塞轻量浮条 (DropHintPopover)** 协同的高速编排工作流。

---

## 改动缘由与核心设计目标

- **消除模态弹窗的打断感**：在决斗残局与 Combo 教学制作中，作者经常需要连续摆放数张卡片。若每次落子都弹出模态框询问表示形式，会强行打断操作心流。
- **引入 `Ctrl` 拖拽切换默认放置状态**：
  - 正常拖入：沿用区域惯例（魔陷默认盖放、怪兽默认表攻、手牌默认未公开）；
  - 按住 `Ctrl` 拖入：一键切换默认放置状态（魔陷直接表侧发动、怪兽直接盖放守备、手牌直接公开）。
  - _选用 `Ctrl` 是由于 Chromium 会把 `Shift+鼠标左键按下` 识别为文本框光标选区扩展，从而拦截原生 HTML5 `dragstart` 拖拽事件；`Ctrl` 拖拽是标准的复制手势，不存在事件冲突。_
- **轻量非阻塞落子切换条 (DropHintPopover)**：落子瞬间在目标格浮出微型胶囊按钮（怪兽区：表攻/表守/盖守；魔陷区：盖放/发动）。该浮条完全不拦截鼠标，作者可立即继续拖拽下一张卡（新落子自动替换旧浮条），亦可通过 Esc 或点击外部随意关闭。
- **槽位视觉中性化重构**：将各区域槽位色彩收敛为中性通用基调 `NEUTRAL_BASE`，消除原本大面积花花绿绿且在浅色模式下暗色泥泞的渐变色块，仅在 EMZ 保留微弱蓝调氛围光与虚线边框。

## 各模块代码改动明细与 Diff

### **src/renderer/src/utils/zoneDrop.ts**

- **改动缘由**：新建纯函数工具 `getDropPosOverride(location, invert)`。当编排者按住 `Ctrl` 拖拽卡片落入区域时切换默认放置状态：魔陷区直接表侧发动 (`FACEUP`)、怪兽区直接里侧守备 (`FACEDOWN_DEFENSE`)、手牌直接公开 (`FACEUP`)。

```diff
+import { CardLocation, CardPosition } from '@shared/index'
+
+/**
+ * 按住 Ctrl 拖放时切换默认放置状态：
+ * 魔陷直接发动 / 怪兽盖放守备 / 手牌公开；松开 Ctrl 则沿用区域默认状态
+ *
+ * @param location 目标落子区域 (CardLocation)
+ * @param invert 是否按住 Ctrl 键切换状态
+ * @returns 覆盖后的表示形式 (CardPosition)，undefined 表示沿用默认
+ */
+export function getDropPosOverride(location: number, invert: boolean): number | undefined {
+  if (!invert) return undefined
+  if (location === CardLocation.SZONE) return CardPosition.FACEUP
+  if (location === CardLocation.MZONE) return CardPosition.FACEDOWN_DEFENSE
+  if (location === CardLocation.HAND) return CardPosition.FACEUP
+  return undefined
+}
```

### **src/renderer/src/stores/useDropHintStore.ts**

- **改动缘由**：新建轻量状态库，管理落子表示切换条的目标格子坐标 `zone: { controller, location, sequence }`。每次在怪兽区或魔陷区落子后激活提示，全局单例设计，新落子自动替换旧提示，非阻塞，可通过 Esc 或点击外部随意关闭。

```diff
+import { create } from 'zustand'
+
+/** 落子表示切换条的目标格子坐标 */
+export interface DropHintZone {
+  /** 控制者 (0: 我方, 1: 对方) */
+  controller: 0 | 1
+  /** 区域 (CardLocation，通常为 MZONE 或 SZONE) */
+  location: number
+  /** 格子序号 (0~4) */
+  sequence: number
+}
+
+interface DropHintState {
+  /** 最近一次落子的格子坐标（仅怪兽/魔陷区），null 表示无浮出提示 */
+  zone: DropHintZone | null
+  /** 显示指定格子的落子表示切换条 */
+  show: (zone: DropHintZone) => void
+  /** 关闭落子表示切换条 */
+  close: () => void
+}
+
+/**
+ * 落子提示状态：每次向怪兽/魔陷区放置卡片后，在该格上方浮出轻量表示切换条。
+ * 同一时刻只保留最新一次落子的提示（新落子自动顶掉旧的），点击外部/Esc 关闭。
+ */
+export const useDropHintStore = create<DropHintState>((set) => ({
+  zone: null,
+  show: (zone) => set({ zone }),
+  close: () => set({ zone: null })
+}))
```

  - **拖拽落地接入切换覆盖**：落子时调用 `getDropPosOverride(location, e.ctrlKey)`，并将结果传递给 `addCardToZone` / `moveCard`。
