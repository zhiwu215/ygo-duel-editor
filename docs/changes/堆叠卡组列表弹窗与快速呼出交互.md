# 游戏王决斗编辑器：堆叠卡组列表弹窗与快速呼出交互

本改动属于一次独立的原子化功能提交，旨在解决堆叠型区域（额外卡组、主卡组、墓地、除外区）因卡片重叠放置而无法查阅内部构成的问题。通过构建全局轻量状态管理、槽位双击与胶囊按钮快速呼出、精简槽位多余计数、以及中央战场局域遮罩（保持左侧详情面板常驻通透清晰），建立起卡堆列表查看的基础交互骨架。

---

## 改动缘由与核心设计目标

- **消除堆叠盲区与提供全局列表视窗**：额外卡组（通常 15 张）与主卡组（40~60 张）在场面上仅以单格堆叠呈现。引入 `usePileListStore` 管理当前查看的目标堆叠区域，支持对双方的额外卡组、主卡组、墓地、除外区一键呼出横向平铺列表弹窗。
- **双击槽位与胶囊徽章双入口极速呼出**：
  - 双击任何堆叠区域格子即可直接呼出列表弹窗；
  - 槽位右上角的张数徽标升级为带悬浮放大的可点击胶囊按钮，单击同样可直接打开列表。
- **精简槽位冗余数字**：移除堆叠槽位右上角和左下角无实际操作意义的静态数字标识，仅保留右上角交互式张数胶囊，界面视觉更清爽纯粹。
- **决斗场中央局域遮罩（Scoped Backdrop）**：
  - 传统全屏遮罩会导致左侧卡片详情面板一同被压暗和高斯模糊，使得编排者在检视列表卡片时无法清晰阅读卡片攻守、效果文本与卡密；
  - 本设计将弹窗遮罩精准锚定在 `DuelBoard` 中央战场容器内（`absolute inset-0 z-40`），左侧卡片详情栏 100% 保持清晰通透，鼠标悬浮列表卡片时左侧能够自由滚动阅读和划选复制文字。
- **帮助系统收录**：在「帮助 -> 快捷键参考」弹窗中补充「双击堆叠格」快速查看列表的使用说明。

## 前端设计思考与样式体系

### 槽位徽章与双击交互 (`ZoneSlot.tsx`)

- **张数徽标按钮**：
  `absolute top-1.5 right-1.5 z-20 px-1.5 py-0.5 rounded-full bg-black/80 border border-white/25 text-[9px] font-mono font-bold text-white leading-none shadow-sm transition-all hover:bg-blue-600 hover:scale-110 cursor-pointer pointer-events-auto`
  - 将原本纯静态的 `div` 升级为具备清晰悬浮反馈的 `button`；
  - `hover:bg-blue-600 hover:scale-110`：鼠标滑过时高亮变蓝并放大 10%，明确传递「可点击交互」暗示；
  - `onDoubleClick` 挂载于槽位根节点，触发 `openPile(controller, location)`。

### 双击打开列表与徽标按钮的实现机制

#### 双入口交互设计的动机

为了兼顾不同习惯的操作者，列表弹窗提供了两种互补的呼出方式：

- **快速盲操流**：鼠标无需精确定位，只要悬停在卡堆格子的任意有效区域，连续双击即可直接弹出列表；
- **视觉微件流**：对于习惯寻找明确可交互按钮的用户，右上角的张数小药丸提供了显式的点击通道。

#### 外层容器的原生双击挂载

真正的双击事件监听器是直接绑定在卡堆格子最外层的父级容器 `div` 上的：

- 在 `ZoneSlot` 根节点上挂载了原生 `onDoubleClick` 监听：
  ```tsx
  onDoubleClick={() => {
    if (isPileZone && count !== undefined && count > 0) {
      openPile(controller, location)
    }
  }}
  ```
- 只要光标落在该格子的任何有效几何范围内（无论是中间的卡面、卡背还是边框区域），双击都会立即触发 `openPile` 呼出弹窗，实现无阻碍盲操。

#### 右上角张数徽标 button 的单击支持

在 JSX 内部看到的 `<button>` 组件，并非用于双击，而是右上角的张数微型胶囊徽标：

- 原本该处仅为一个用于展示卡牌张数（如 `15`）的静态 `div` 标签；
- 本次改动将其重构为语义化的 `<button type="button">`，使其具备完整的悬浮（Hover）高亮动效与微交互反馈；
- 用户只需鼠标单击右上角变蓝的数字药丸，便能直接调用 `openPile(controller, location)` 呼出列表，为喜欢鼠标点击的用户提供一目了然的操作抓手。

#### stopPropagation 阻断事件冒泡

右上角张数胶囊按钮在触发 `onClick` 时显式调用了 `e.stopPropagation()`：

- 点击数字胶囊时，能够精准阻断点击事件向上冒泡到外层格子的 `onClick`（该事件负责选中/取消选中场上卡片）；
- 保证打开列表的操作纯粹独立，不会伴随触发卡片选中状态的非预期跳变。

### 中央局域遮罩设计 (`DuelBoard.tsx`)

- **战场范围内的 Scoped Backdrop**：
  `DuelBoard` 作为定位上下文（`relative overflow-hidden`），`PileListModal` 单例挂载在其内部：
  - 遮罩采用 `absolute inset-0 z-40 bg-black/60 backdrop-blur-xs`，仅遮蔽中间决斗台网格；
  - 渲染进程三栏布局中的左侧 `CardDetailPanel` 与右侧 `CardSearchPanel` 均不处于 `DuelBoard` 容器内，因此完全不受遮罩与高斯模糊影响，卡片属性与效果文本始终保持高保真通透。

## 各模块代码改动明细与 Diff

### **src/renderer/src/stores/usePileListStore.ts**

- **改动缘由**：新建堆叠区域弹窗全局状态管理器，记录目标控制者与区域坐标，提供 `openPile` 与 `closePile`。

```diff
+import { create } from 'zustand'
+
+/** 堆叠卡片列表弹窗的目标区域参数 */
+export interface PileListTarget {
+  /** 控制者 (0: 我方, 1: 对方) */
+  controller: 0 | 1
+  /** 区域 (CardLocation，如 EXTRA / DECK / GRAVE / REMOVED) */
+  location: number
+}
+
+interface PileListState {
+  /** 当前正在查看列表的目标区域坐标，null 表示弹窗处于关闭状态 */
+  target: PileListTarget | null
+  /** 打开指定堆叠区域的卡片列表查看弹窗 */
+  openPile: (controller: 0 | 1, location: number) => void
+  /** 关闭卡片列表查看弹窗 */
+  closePile: () => void
+}
+
+/**
+ * 堆叠区域（主卡组、额外卡组、墓地、除外区）卡片列表查看弹窗状态管理。
+ */
+export const usePileListStore = create<PileListState>((set) => ({
+  target: null,
+  openPile: (controller, location) => set({ target: { controller, location } }),
+  closePile: () => set({ target: null })
+}))
```
